# Community projects for Agent Framework

> [!IMPORTANT]
> The projects on this page are created and maintained outside the Microsoft
> Agent Framework team. Microsoft doesn't own, test, or support these projects.
> Listing a project doesn't imply Microsoft endorsement or confirm compatibility
> with any Agent Framework version. For compatibility information, support, and
> issue handling, contact the project maintainer through the project's
> repository and issue tracker.
> For security concerns, follow the maintainer's security reporting guidance.

:::zone pivot="programming-language-csharp"

Community members maintain projects that integrate with or extend Microsoft
Agent Framework. To request inclusion, open a pull request against the
[.NET catalog](https://github.com/microsoft/agent-framework/blob/main/dotnet/samples/community-projects.md)
in the Agent Framework repository.

No .NET community projects are listed yet.

:::zone-end

:::zone pivot="programming-language-python"

Community members maintain projects that integrate with or extend Microsoft
Agent Framework. To request inclusion, open a pull request against the
[Python catalog](https://github.com/microsoft/agent-framework/blob/main/python/samples/community-projects.md)
in the Agent Framework repository.
