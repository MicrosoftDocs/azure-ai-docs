# Mistral integrations

The Agent Framework Mistral integration for Python supports chat agents and
text embeddings. Chat features include streaming, function tools, structured
output, image and PDF inputs, and reasoning content on supported models.

| Scenario | Guide |
|---|---|
| Create a Mistral chat agent and use supported chat capabilities. | [Mistral model provider](../by-component/model-providers/mistral.md#create-a-chat-agent) |
| Generate embeddings with Mistral AI or a compatible Mistral endpoint. | [Mistral model provider](../by-component/model-providers/mistral.md) |
| Use embeddings and retrieval in an Agent Framework agent. | [RAG capabilities](../../agents/rag.md) |
