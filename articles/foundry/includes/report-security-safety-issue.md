Security researchers and customers play a crucial role in protecting AI. To report security vulnerabilities or safety problems in Foundry Models sold by Azure, go to the [Microsoft Security Response Center (MSRC)](https://www.microsoft.com/msrc/faqs-report-an-issue). Examples of vulnerabilities include prompt injection, unsafe output, and data exposure. When reporting a problem, include the model name and version, the steps that led to the problem, and the potential impact.
